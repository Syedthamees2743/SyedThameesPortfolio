    THE CASE PANS SIDEWAYS
    02The Problem

    Support requests don't fail loudly — they get lost between roles.

    P.01
    Three roles, one workflow

    Admin, Employee and Technician each require dedicated portal states without fragmenting collaboration.

    P.02
    Status without visibility

    Once a request is filed, progress must be trackable — ownership and status updates cannot live in inboxes.

    P.03
    Time that must be tracked

    Response and resolution windows require explicit SLA timers rather than loose estimates.

    03The Solution

    A unified platform where every ticket has a role, an owner, a status — and a clock.

    S.01
    Role-based access with JWT authentication

    Secure token-based sessions across Admin, Employee and Technician roles.

    S.02
    React frontend over Django REST APIs

    State hydration handled via Axios into a fast responsive interface.

    S.03
    PostgreSQL as single source of truth

    Relational consistency enforced through Django ORM across tickets, assets and audit logs.

    04Architecture

    JWT-SECURED REST LAYER BETWEEN REACT AND POSTGRESQL — SMTP NOTIFICATIONS
